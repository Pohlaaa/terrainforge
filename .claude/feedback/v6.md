## Project Wizard

- **🟡 Enter should advance the wizard between pages.**
  - **Fix shipped** `ad20075`. Global keydown handler in `ProjectWizard.tsx`
    advances on Enter, skipped inside textareas / contenteditable / on the last
    step (Create stays explicit-click) / when `defaultPrevented` is true.
- **🟡 Design page issues: "Very glitchy. 3D does not work at all."**
  - `3D doesn't work` traced to F-3D-MESH-01 (camera framing pulled the lens to
    parcel-scale; element heights were 0.1 ft so they read as sub-pixel slabs;
    z-fighting between element bottoms and the satellite ground at depth-buffer
    resolution at 800+ ft camera distance). **Shipped** `e2a539b` — element-priority
    framing, ground plane offset to y=-0.05, hardscape thickness defaults bumped.
  - `Items not to scale` was a separate scale bug — the satellite `<img>` was
    rendered as `objectFit: cover` filling the container regardless of geographic
    footprint, while the SVG viewBox was sized to the element bbox. **Fix
    shipped** `62956ec` — render satellite as `<image>` inside the SVG so it
    shares plan-feet space.
  - `Items not attempting to place correctly on the property` — the bigger
    architectural fix. Sprint AI-Place shipped `13073ca` + `5bb0b54`: Claude
    Haiku 4.5 vision call inside `proxy-claude` with the satellite tile, returns
    normalized [0,1] coords + per-element rationale + buildable polygon +
    obstacle polygons. Mapped to plan-feet via Web Mercator. Geocode fallback
    when contractor types address without picking from autocomplete (`62956ec`).
  - `I should be able to delete the auto-generated highlighted area` — the
    Sprint AI-Buildable green polygon overlay. **Fix shipped** `ad20075` — Hide
    overlay / Show overlay toggle on the AI-placed banner, persisted to
    localStorage.
  - `Inability to remove items` — **Fix shipped** `62956ec`. Delete/Backspace
    on selected element + per-thumbnail × button (low-opacity hover-revealed,
    auto-selects next element after delete).
  - `Scale bar not to scale` — closed by the same scale fix as items-to-scale.

- **🟡 Materials qty doesn't auto-update on sqft change. Have to leave the step and come back.**
  - **Fix shipped** `ad20075`. New `src/lib/scaleAIQuantity.ts` proportionally
    scales the AI's `estimatedQuantity` by current-vs-baseline area (or
    linearFt for LF units) ratio. Captured in cache at fetch time. 8 unit
    tests. Same scaling applied at accept-time so contractor's selections
    match what's displayed.

- **🔴 Schedule should be its own dedicated page.**
  - jbluhm: "I think the schedule should be its own defined page that can be
    edited & changed at any given moment." Today's schedule UI is scattered
    across Work Orders / Resources tab / Crew + Equipment Hub.
  - **Deferred** — listed as "Sprint Schedule" in ROADMAP. Bigger UX refactor.

### Materials section UI

- **🟡 Tabs should be reordered: Material Library → Suppliers → Inventory On Hand.**
  - **Fix shipped** `ad20075`. Library is now the default landing tab.

- **🔴 Material Library should only show used/quoted materials + favorites.**
  - jbluhm: "Only Materials used or quoted should be in that list. Also, any
    Materials that the Contractor puts into Favorites."
  - **Deferred** — needs a `materials.is_favorite` flag and a usage-tracking
    join. Not blocking; current "all materials" view works.

- **🟡 Suppliers: per-supplier pricing instead of "useless contact info only."**
  - **Fix shipped** `e31474e`. CSVImportModal got a "Import for supplier"
    picker. When set:
    1. SKUs prefixed with the supplier's `short_code` (RH-PAVER-12) — mig 036.
    2. Each successfully-imported material linked via a `supplier_prices`
       junction row carrying unit_cost + sku.
  - SupplierFormModal got a "Short Code" field with 2-6 char A-Z0-9
    validation, placeholder "e.g. RH", hint "Prefixes SKUs at CSV import".

- **🟡 CSV import broken at ~50 rows.**
  - Root cause: regex parser misparsed quoted fields containing commas /
    escaped quotes / embedded newlines. A row past 50 with any of these
    shifted every subsequent row's columns by one, the DB silently rejected
    the malformed inserts.
  - **Fix shipped** `e31474e`. New `src/lib/csvParse.ts` is a proper RFC 4180
    tokenizer. 12 unit tests covering the real failure modes including a
    200-row synthetic file with a tricky row at position 51.

- **🟡 CSV imports should make IDs based on the supplier prefix.**
  - **Fix shipped** `e31474e` (mig 036) — see "per-supplier pricing" above.
