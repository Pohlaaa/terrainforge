Spacing & Density Guide
Reference for implementing density changes across all pages. The core pattern: reduce card padding, use border-based grids instead of gap-based grids, and go horizontal with metadata.
Before — Current Issues
• Card padding: 20px (too airy)
• Grid gaps: 16px (wastes space)
• KPI cards: full-height standalone
• Meta layout: stacked vertically
• Project names: truncated at 1 line
• 3-column grid on tablet (too tight)
• Map: zoomed to continent
• Empty START/TARGET rows showing
After — Fixes Applied
• Card padding: 12-14px (tight but readable)
• Grid: border-separated (0 gap, border dividers)
• KPIs: inline strip, 4-across, ~56px tall
• Meta layout: inline horizontal row
• Project names: 2-line wrap with clamp
• 2-column grid on tablet + list view option
• Map: zoomed to metro/project cluster
• Empty fields hidden, not displayed

Key Principle: Border Grids vs Gap Grids
Instead of display: grid; gap: 16px, use gap: 0 with border-bottom and border-right on children. This eliminates visible whitespace between items while maintaining visual separation. The map and widgets already share borders, creating a dense, app-like feel instead of a dashboard-with-cards feel.
